Weather App

Application web simple permettant d’afficher la météo en temps réel pour n’importe quelle ville. Développée avec HTML, CSS et JavaScript, et utilisant WeatherAPI.

Fonctionnalités :

Recherche de n’importe quelle ville

Affichage de la température, humidité, vent, pression, UV, etc.

Interface moderne (Glassmorphism)

Loader animé

Gestion des erreurs
